# AGIT

Закрытая система штаба и полевой работы агитаторов: задания на карте, маршруты, геопроверка и фотоотчёты через VK.

## Основной сценарий штаба

Штаб сразу открывается на большой рабочей карте. На компьютере действия находятся в компактной правой панели, а на телефоне — в нижней выдвижной панели.

1. На карте поставить два угла территории.
2. Выбрать агитатора.
3. Нажать «Добавить, назначить и построить маршрут».

Во вкладке «Маршруты» штаб может открыть маршрут любого агитатора на карте, перестроить его по соседним домам или адресу, начать от своей геопозиции, развернуть порядок, перенести не начатые дома другому человеку и быстро очистить маршрут. Очистка снимает только задания без истории — отчёты и фотографии защищены.

AGIT получает адресные точки OpenStreetMap через Overpass, автоматически переключается между резервными серверами, не создаёт дубли и отбрасывает школы, больницы, госучреждения и другие явно нежилые объекты. Адреса из `associatedStreet` тоже распознаются. Перед назначением любую лишнюю синюю точку можно исключить одним нажатием. Затем система массово назначает дома и строит простой порядок обхода. Отдельно доступны поиск адреса через Nominatim, ручное добавление дома, массовый выбор уже сохранённых точек и перестроение маршрута.

## Возможности

- вход агитатора по одноразовой ссылке из VK;
- мобильный экран «Сейчас» с ближайшим домом и переходом в Яндекс Карты;
- маршрут с номерами домов и перестроением от текущей геопозиции;
- проверка расстояния до дома перед сдачей отчёта;
- приём 1–5 фотографий из сообщений VK;
- уведомление штаба о новом отчёте;
- уведомление агитатора в VK: принято или конкретная причина переделки;
- статистика по каждому агитатору и журнал действий;
- безопасная схема фото: ZIP → подтверждение выгрузки → отдельное удаление;
- фотографии хранятся вне web-каталога в `/var/lib/agit/photos`.

## Развёртывание и обновление

На VPS от root:

```bash
curl -fsSL https://raw.githubusercontent.com/TimurNTa/agit/main/deploy/bootstrap.sh | bash
```

Первичная настройка секретов выполняется в `/var/www/agit/.env`. Скрипт сохраняет действующий пароль PostgreSQL, применяет миграции, проверяет типы и тесты, собирает проект, выполняет настоящий `systemctl restart agit` и health-check.

Секреты VK, пароль штаба и `SESSION_SECRET` никогда не добавляются в GitHub.
